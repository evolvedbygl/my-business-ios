# My Business - Evolved by GL

Estimates, invoices, scheduling, payroll, and 1099s for the trades. A native SwiftUI app for iPhone and iPad.

Download it on the [App Store](https://apps.apple.com/app/id6778954606).

## What is in this repository

- `GLSmallBusiness/` - the app: SwiftUI screens, domain services, models, and sync.
- `GLSmallBusinessTests/` and `GLSmallBusinessUITests/` - unit and UI tests.
- `GLSmallBusiness.xcodeproj` - the Xcode project and its test plans.

## What is not in this repository

- Backend services, deployment and release tooling, credentials, and internal documentation.

## Building

The app depends on private Gold Life packages (GoldLifeUI, GoldLifeID, GoldLifeCloud, GoldLifeAI, and GoldLifeDocuments) that are not published. This code will not build outside Gold Life.
